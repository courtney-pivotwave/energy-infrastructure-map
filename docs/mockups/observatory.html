infrastructure.json · status.json · assets

Every mapped asset, one square each

Coloured from the date its current disruption began. Scrub back before 28 February and the board goes quiet.

Only each asset's current status and its start date are stored, so earlier changes (repairs, reopenings) don't show up when you scrub back.

An experiment from Strategic Energy Map, a free, ad-free public resource. Data snapshot ; sources and methods on the About page. Colour maps: inferno and viridis (Smith & van der Walt, matplotlib), cividis (Nuñez et al., 2018, designed for colour-vision deficiency).
